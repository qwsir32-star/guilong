<h1 align="center">归拢</h1>

<p align="center"><strong>散着的标签页，归拢一下。</strong></p>

<p align="center">可视化的多标签页管理扩展 · Chrome / Edge / Firefox · 无服务器 · 不收集数据</p>

---

归拢把你此刻开着的标签页，全部摆到一张图上。

它接管你的新标签页，按域名分成一卡一卡，摊成网格。哪个站开了多少个、哪些其实开重了、哪些只是先放着回头再看，扫一眼就明白，不用再一个标签一个标签地翻。

- 找东西不用一个个点过去，它们都在那儿摊着
- 整组一起关掉，手起刀落，还配了音效和彩带
- 舍不得关的先存着，回头处理完归档，哪天想起来还能翻出来

顺眼的留着，不顺眼的关掉。常用站点条、搜索框、天气都能单独关，主题色八套，中英双语。

## 为什么做这个

标签页开着开着就多了，然后就开始难受。

想找的那个混在几十个里，只好一个个点过去。明知道一半用不上了，也不敢关，万一等会儿还要看呢。资料查到一半，浏览器就不能关，关掉等于丢掉。

归拢就是为这三件事写的。摊开看清，整组关掉，关之前先存下来。

## 功能

| 功能 | 说明 |
|---|---|
| 按域名分组 | 同一个站的收进一张卡，网格排开 |
| 主页单独成组 | Gmail 收件箱、X 首页、YouTube、GitHub 主页收成一张，一次关干净 |
| 重复检测 | 同一个页面开了两遍会被标出来，一键清掉 |
| 点标题就跳 | 点标题直接跳过去，跨窗口也行，不多开一个 |
| 本地项目分组 | localhost 后面带端口号，几个项目分得清 |
| 关得爽 | 关的时候有合成音效和粒子彩带 |
| 稍后再看 | 关之前先存着，处理完归档，之后还能搜回来、还原回来 |
| 常用站点条 | 常去的钉在顶部，按住能拖着排序，一点就到（可关） |
| 搜索框 | 输入网址直接开，否则交给你自己设的搜索引擎（可关） |
| 当地天气 | 图标、气温、城市、今天的最高最低，一行放下（可关） |
| 主题色 | 八套，含跟随系统 |
| 呼出快捷键 | 默认 `⌘⇧K` / `Ctrl+Shift+K`，设置里能看到当前绑定 |
| 工具栏图标 | 点一下把面板叫出来，角标显示标签页数 |
| 中英双语 | 默认中文 |

设置里那些开关只管显示，不删数据。关掉再打开，钉住的站点和存下的清单原样还在，别担心。

## 安装

从商店装最省事。Chrome、Edge、Firefox 三家上架之后，链接会补在这里。

等不及的话，「自己构建」那节有命令。

## 浏览器支持

| | 版本要求 |
|---|---|
| Chrome | 支持 Manifest V3 的版本 |
| Edge | 同上，跟 Chrome 共用同一个包 |
| Firefox | 142.0 及以上 |

## 隐私

你的标签页、钉住的站点、稍后再看、还有设置，全在浏览器本地待着，哪儿也不去。

只有天气得出门一趟，发的是你选的城市坐标，两个数字。标签页数据、浏览历史、设备标识、cookie，一概不带。把天气开关关掉，它就彻底不出门了。

每一项权限是干什么的，[PRIVACY.md](./PRIVACY.md) 里写着。

## 自己构建

```bash
git clone https://github.com/qwsir32-star/guilong.git
node tools/build-store.js     # 生成 dist/ 下三个商店包
node tests/smoke.js           # 冒烟测试，一秒内跑完
```

Chrome 和 Edge 直接加载 `extension/` 文件夹就行，没有构建这一步。Firefox 的加载方式见 [Firefox 安装指南](docs/firefox-安装指南.md)。架构、目录结构和各种技术取舍见 [工程笔记](docs/工程笔记.md)。
