<h1 align="center">归拢</h1>

<p align="center"><strong>散着的标签页，归拢一下。</strong></p>

<p align="center">可视化的多标签页管理扩展 · Chrome / Edge / Firefox · 无服务器 · 不收集数据</p>

---

归拢接管你的新标签页，把它换成一张可视化总览。此刻开着的标签页按域名摆成网格，哪个站开了多少个、哪些其实开重了、哪些只是先放着回头再看，一眼扫完。

- 几十个标签页摊在一张图上，找东西不用一个个点过去
- 同一个站的标签页收在一张卡里，整组一次关干净，关的时候有音效和彩带
- 舍不得关的先存进「稍后再看」，处理完归档，之后还能搜回来、还原回来

常用站点条、搜索框、天气都能单独关掉，主题色八套可选，界面中英双语。

## 为什么做这个

标签页开多了会变成负担。

想找的那个混在几十个标签里，只能一个个点过去找。明知道一半用不上了，也不敢关，万一等会儿还要看。资料查到一半，浏览器就不能关了，关掉等于丢掉。

归拢把这三件事一起解决。摊开看清，整组关掉，关之前先存下来。

## 功能

| 功能 | 说明 |
|---|---|
| 按域名分组 | 打开的标签页按站点收进卡片，网格排开 |
| 主页单独成组 | Gmail 收件箱、X 首页、YouTube、GitHub 主页收成一张卡，一次关干净 |
| 重复检测 | 同一个页面开了两遍会被标出来，可一键清理 |
| 点标题就跳 | 点任意标签页标题直接跳过去，跨窗口也行，不会多开一个 |
| 本地项目分组 | localhost 后面显示端口号，几个项目分得清 |
| 关得爽 | 关闭时合成音效，加粒子彩带 |
| 稍后再看 | 关之前先把想留的存进清单，处理完的归档，之后还能搜回来、还原回来 |
| 常用站点条 | 常去的站点钉在顶部，可按住拖动排序，一点就到（可关） |
| 搜索框 | 输入网址就直接打开，否则交给你自己设的默认搜索引擎（可关） |
| 当地天气 | 页头下面一行，图标、气温、城市、今天的最高最低（可关） |
| 主题色 | 八套可选，含跟随系统 |
| 呼出快捷键 | 默认 `⌘⇧K` / `Ctrl+Shift+K`，设置面板里能看到当前绑定 |
| 工具栏图标 | 点一下把仪表盘叫出来，角标显示标签页数 |
| 中英双语 | 默认中文 |

设置面板里的每个开关只控制显示，不删数据。关掉再打开，钉住的站点和存下的清单原样还在。

## 安装

从商店装最省事。Chrome、Edge、Firefox 三家上架后，下载链接会放在这里。

现在就想试的话，见下面的「自己构建」。

## 浏览器支持

| | 版本要求 |
|---|---|
| Chrome | 支持 Manifest V3 的版本 |
| Edge | 同上，与 Chrome 共用同一个包 |
| Firefox | 142.0 及以上 |

## 隐私

标签页数据、钉住的站点、稍后再看、设置，全部存在浏览器本地，不往任何服务器发。

唯一一次对外请求是天气，发的是你选的城市坐标，就两个数字，不带标签页数据、浏览历史、设备标识、cookie。把设置里的天气开关关掉，一次请求都没有。

完整说明见 [PRIVACY.md](./PRIVACY.md)，里面有每一项权限是干什么的。

## 自己构建

```bash
git clone https://github.com/qwsir32-star/guilong.git
node tools/build-store.js     # 生成 dist/ 下三个商店包
node tests/smoke.js           # 冒烟测试，一秒内跑完
```

Chrome 和 Edge 直接加载 `extension/` 文件夹就行，不需要构建。Firefox 的加载方式见 [Firefox 安装指南](docs/firefox-安装指南.md)。架构、目录结构和各项技术取舍见 [工程笔记](docs/工程笔记.md)。
