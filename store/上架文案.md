## 通用

### 名称

```
归拢 · 新标签页
```

（7 个字符，三家都远在上限内：Chrome 45 / Edge 45 / Firefox 50）

### 一句话简介

```
把散着的标签页归拢到一处：按域名分组、一键关干净、没看完的先存起来。
```

### 详细描述（三家通用版）

```
散着的标签页，归拢一下。

归拢接管你的新标签页，把你此刻开着的所有标签页按域名摆成一张网格仪表盘：
哪个站开了多少个、哪些其实开重了、哪些只是"先放着回头再看"，一眼扫完。

【一眼看尽】
打开的标签页按域名分组，网格排开。主页类站点（Gmail 收件箱、X 首页、
YouTube、GitHub 主页）单独收成一张卡片，一次关干净。

【关得爽】
关闭时合成音效 + 粒子彩带。重复开了两遍的页面会被标出来，可一键清理。

【稍后再看】
舍不得关的先存进清单；处理完的归档，之后还能还原回来。

【常用站点条】
常去的站点钉在顶部，可按住拖动排序，一点就到。

【当地天气】
页头下面一行：图标 + 气温 + 城市 + 今天的最高最低。城市在设置里搜着选，
可以整个关掉。

【主题色】八套可选，含跟随系统。
【中英双语】默认中文，界面文案集中在同一张表里。

【隐私】
没有服务器、不用账号、不需要 API key。标签页数据、钉住的站点、稍后再看、
设置全存在浏览器本地，不往任何服务器发。唯一的对外请求是天气：发的是你选的
城市坐标两个数字，不带标签页数据、浏览历史、设备标识、cookie。
不想发就把天气开关关掉。

【开源】
MIT 许可，源码在 GitHub 上：https://github.com/qwsir32-star/guilong
```

## Chrome Web Store

- **费用**：开发者账号一次性 5 美元（不是每个扩展）。
- **图标**：128×128 PNG（`extension/icons/icon128.png`，现成的）。
- **截图**：至少 1 张，**1280×800 或 640×400**，最多 5 张。
- **宣传图**（可选但要凑齐才好看）：
  - 小方块 440×280
  - 大方块 920×680
  - 横幅 1400×560
- **数据安全表单**（Data Safety）——照下面填：
  - 是否收集用户数据：**否**
  - 是否用于**与用户无关的**目的（分析/广告）：**否**
  - 数据是否加密传输：不适用（不外发）
  - 单点用途声明（Single purpose）：「Manage and organize open browser tabs」
- **审核**：首次通常 1–3 天。

### 权限说明（CWS 会让你逐条解释用途）——照抄

| 权限 | 说明 |
|---|---|
| `tabs` | 读取当前打开的标签页（网址、标题）以按域名分组展示；关闭与切换标签页。数据仅在本机处理，不外发。 |
| `activeTab` | 同上，浏览器在用户操作时临时授予。 |
| `storage` | 在本地保存用户钉住的站点、「稍后再看」清单、显示开关与主题偏好。 |
| `topSites` | 读取浏览器「最常访问」列表，用于自动补足常用站点条。不外发。 |
| `favicon` | 读取浏览器本地缓存的站点图标（`_favicon` 端点），是本地读盘，不向站点发请求。 |
| `search` | 把用户输入的关键词交给用户自己设置的默认搜索引擎。扩展不指定也不记录是哪家。 |

## Edge Add-ons

- **费用**：免费，需要一个 Microsoft 合作伙伴中心账号（要有 Microsoft 账户）。
- **包**：**和 Chrome 用同一个 zip**（`dist/guilong-<版本>-chrome.zip` 或 `-edge.zip`，内容完全一样）。Edge 是 Chromium，不需要任何改动。
- **截图**：至少 1 张，尺寸与 Chrome 通用（1280×800）。
- **审核**：通常比 Chrome 快一些。

Edge 的后台字段比 Chrome 少，名称和描述直接复用上面的通用版即可。

## Firefox (AMO)

- **费用**：免费。
- **包**：`dist/guilong-<版本>-firefox.zip`（**不能用 Chrome 那个**）。
- **名称上限 50**，**简介上限 250**（上面的都远在范围内）。
- **截图**：至少 1 张，建议 3–5 张，宽度 ≥1000px 看着最清楚。
- **首页**：填 GitHub 地址。
- **隐私政策**：填 `PRIVACY.md` 的地址。

### AMO 的三条硬要求（打包脚本已经做好了，这里记录一下为什么）

1. **`data_collection_permissions`** —— 2025-11 起所有新扩展必填。归拢写的是
   `{ "required": ["none"] }`，意思是什么都不收集。
2. **`browser_specific_settings.gecko.id`** —— MV3 签名必填，AMO 不再自动分配。
   归拢用的是 `guilong@qwsir32-star.github.io`。**首次提交就定死，之后别改。**
3. **`strict_min_version: "142.0"`** —— 版本地板是算术：根证书过期要 ≥115 ESR/128，
   后台双键要 ≥121，`data_collection_permissions` 要桌面 ≥140 / Android ≥142。
   取 142 三个都过，lint 一条警告都没有。

### 提交时要勾的

- **兼容平台：只勾 Desktop。** Firefox for Android **不支持** `chrome_url_overrides`
  （抢新标签页在 Android 版上根本不生效），勾上去就是个坏的核心功能。
- **源码提交**：归拢是零构建的 —— 上传的就是你写的那份源码，没有压缩也没有打包器，
  所以**不需要**走「提交构建产物 + 源码」那道关。真被问到，给 GitHub 仓库地址即可。

### 提交前跑一次

```bash
npx web-ext lint dist/firefox
```

目标：**0 errors / 0 warnings / 0 notices**。

### 审核备注（Reviewer notes）里建议主动说明

> 这个扩展会联网一次：向 Open-Meteo 的公开预报接口发送用户选择的城市坐标
> （两个数字），用于显示气温。城市搜索是离线的（用随扩展打包的本地城市库）。
> 除此之外没有任何外发。可以在设置里关掉天气。

主动说比被问到再说快得多 —— 审核员看到「新标签页扩展为什么要联网」一定会问。
